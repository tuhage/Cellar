# Security Policy

## Supported versions

Security fixes are provided in the latest release of Cellar. Please update to the
latest version before reporting an issue.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/tuhage/Cellar/security/advisories/new).
Avoid posting security details in public issues or discussions before a fix is
available.

Include the affected Cellar and macOS versions, steps to reproduce the issue,
and its potential impact. Remove passwords, tokens, and other private information
from logs or screenshots before sending them.

For ordinary bugs and feature requests, use
[GitHub Issues](https://github.com/tuhage/Cellar/issues).
